## 2. Metodologia Central — Método CPF

**C = Conhecimento | P = Posicionamento | F = Faturamento**

**Sequência operacional:**
1. Pesquisa no Answer the Public — descobre o que o público do cliente realmente pergunta
2. Live gravada estrategicamente com o cliente respondendo as perguntas da pesquisa
3. Cortes editados em Shorts com legendas SEO para YouTube, TikTok e Instagram
4. Mentoria de postagem ao cliente (frequência, horário, hashtags, descrição)

**Resultado:** conteúdo com voz real do cliente, otimizado para busca, publicado em escala.
**Precificação de referência (CPF solo):** R$1.800–R$2.500/mês por cliente

- [27–30 min] CTA em 3 camadas

**Regras absolutas da palestra:**
- Máximo 16 slides em 30 minutos
- Pandemia antes dos testimoniais (nunca inverter)
- Sem demo de internet ao vivo
- CTA com scarcity real (vagas limitadas = concorrentes na sala)

## 7. Infraestrutura de CRM e Automação

**Plataforma:** LINKIA (linkia.ai)
**Recursos ativos:**
- Pipelines: arquitetos e corretores (reaproveitamento de stages)
- Automações: WhatsApp API + email como canais duais
- Prospecção local via Google Maps
- Tagging: `[niche]-palestra-[data]` (ex: `corretor-palestra-28abr`)

**Variável de contato:** `{{contact.name}}`
**Tempo mínimo de espera:** 1 minuto (não há opção de segundos)

**Regra crítica de automação:**
- Automação só dispara para leads adicionados APÓS a publicação do fluxo
- Leads pré-existentes não são capturados pelo trigger

**Regra de envio de link no WhatsApp:**
Enviar em 3 blocos separados:
1. Texto completo do convite (sem link)
2. Link isolado
3. Mensagem curta de urgência
*(Necessário para acionar preview de thumbnail)*

## 10. Padrões Técnicos de Produção

**Emails HTML (Gmail-safe):**
- Estrutura: tabelas only
- Fonte: Poppins via Google Fonts + Arial fallback
- Botões: `td bgcolor` + inline styles
- **CRÍTICO — botão:** texto SEMPRE com `<span style="color:#000000 !important;-webkit-text-fill-color:#000000 !important;">` dentro do `<a>`. Só `color:#000000` no `<a>` não funciona no Gmail.

**Imagens para email:**
- Hospedar no Google Drive
- URL: `https://drive.google.com/uc?export=view&id=[FILE_ID]`

**PDFs visuais (sem camada de texto):**
- Rasterizar com `pdftoppm -jpeg -r 120`
- Ler cada `.jpg` individualmente via view tool
